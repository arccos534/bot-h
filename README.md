# Telegram бот для записи к парикмахеру

Бот на `aiogram 3` и `sqlite3`: клиент выбирает дату, время, мастера, услугу из прайса и подтверждает запись через одно саморедактируемое сообщение с inline-кнопками. После подтверждения клиент видит кнопку отмены и связь с администратором, а выбранный мастер получает уведомление.

## Быстрый старт

1. Создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `MASTER_IDS`, `ADMIN_IDS`. Для клиентской кнопки связи можно указать `ADMIN_CONTACT_URL` или `ADMIN_USERNAME`.

3. Запустите бота:

```powershell
python bot.py
```

## Команды

- `/start` - клиентское меню.
- `/master` - админка: одно сообщение с ближайшими записями, сгруппированными по датам.

## Как устроено

- `salon.sqlite3` создается автоматически.
- Мастера и прайс-лист сидируются при старте.
- Черновик выбора даты/времени/мастера/услуги хранится в базе.
- Повторная бронь одного мастера на один слот невозможна, потому что имеет уникальный индекс.
